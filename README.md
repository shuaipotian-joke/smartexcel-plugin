# SmartExcel Plugin

SmartExcel Plugin is an open-source browser extension that detects HTML tables on web pages and exports them to Excel-compatible files.

It is the browser companion of the SmartExcel website (smarterexcel.com). The extension has **no login**: it identifies the browser with a random device ID and asks the website whether that device is activated. A device is activated either with an activation code or by buying directly from the extension (¥9.9 CNY via XorPay or $5 USD via Stripe, one-time, separate from website credits).

## What It Does

- Detects HTML tables on any web page.
- Shows a floating SmartExcel icon when the user hovers over a table (can be switched off in settings).
- Exports a single table as `.xlsx` or `.csv`, from the hover menu, the right-click menu, or the popup.
- Exports all or selected tables from the popup.
- Blocks exports on a device that is not activated, with an "Enter activation code" card and a "Buy" button.
- Activates the device with a single-use activation code, or automatically after a purchase started from the extension (no code needed).
- Displays the UI in Chinese or English from the browser region by default, with a manual switch in settings.

## Activation

| | |
| --- | --- |
| Device ID | Random UUID created on first run, kept in `storage.local` and mirrored to `storage.sync` (survives a reinstall on the same browser profile). |
| Activation codes | Generated by admins on smarterexcel.com. Single-use: one code activates one device, once. Entering a code on an already-active device does not use it up. |
| Buy | Opens `/{zh,en}/plugin-payment?deviceId=…&closeAfterPayment=true`. The payment activates the device on the server; the extension polls the status, unlocks, finishes a blocked export and closes the payment tab it opened. |
| Start-up | A cached activation is trusted immediately (works offline) and re-checked about once a day. Only an explicit "not activated" from the server locks the extension again. |

Endpoints (on `WXT_SMARTEXCEL_URL`, default `http://localhost:42100`, production `https://smarterexcel.com`):

- `POST /api/plugin/activation/activate` `{ code, deviceId, browser?, version? }`: 10 requests per 10 min per IP.
- `POST /api/plugin/activation/status` `{ deviceId }`: 600 requests per 10 min per IP.

See `AGENTS.md` for the full contract, storage keys and the local test setup.

## Project Roles

| Path | Role |
| --- | --- |
| `entrypoints/background.ts` | Message routing, export access check, context-menu actions, Buy and payment-tab watch. |
| `entrypoints/content.tsx` | Content script: detects tables, runs exports, mounts the in-page overlay. |
| `entrypoints/popup/App.tsx` | Popup: detected tables, export buttons, activation card. |
| `entrypoints/popup/SettingsPanel.tsx` | Settings: language, activation status, device ID, "Show table icon on pages". |
| `components/TableOverlay.tsx` | Hover icon, export menu and in-page activation prompt. |
| `utils/activation.ts` | Device ID, activation/status API calls, cached state, purchase page. |
| `utils/use-activation.ts` | Activation-code form hook shared by popup and overlay. |
| `utils/table-parser.ts` | HTML table detection and parsing. |
| `utils/excel-export.ts` | SheetJS-based Excel and CSV generation. |
| `utils/messaging.ts` | Message types shared by popup, content script and background. |
| `utils/store.ts` | Zustand UI preferences (language, table icon). |
| `utils/i18n.ts` | Chinese/English strings and region-aware default language. |
| `utils/theme.ts`, `tailwind.config.ts` | Design tokens. |
| `wxt.config.ts` | Manifest, permissions and browser build setup. |

## Design Direction

Calm, warm and readable:

- warm off-white surfaces;
- clay/terracotta accent;
- soft borders, rounded corners, gentle shadows;
- sans-serif body text with serif headings;
- generous spacing, simple lucide icons, restrained motion.

## Development

Use `npm` in this repository.

```bash
npm install
npm run dev          # Chrome
npm run dev:edge
npm run dev:firefox
```

Point the extension at a local website with `WXT_SMARTEXCEL_URL=http://localhost:42100` in `.env.local`.

## Build And Check

```bash
npm run build          # Chrome MV3
npm run build:edge     # Edge MV3
npm run build:firefox
npm run build:all
npx wxt prepare && npx tsc --noEmit
```

Build outputs are written to `.output/`. For real QA, load `.output/chrome-mv3/` or `.output/edge-mv3/` unpacked and test on pages with real HTML tables.
